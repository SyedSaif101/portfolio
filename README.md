# Syed Saif Gillani — Portfolio

Personal portfolio showcasing my projects, research, technical skills, certifications, and experience.

## Website

[Visit my portfolio](https://syedsaif101.github.io/portfolio/)

## Technology Stack

- React 19
- Vite
- JavaScript
- Tailwind CSS
- GSAP and ScrollTrigger
- Motion

## Features

- Responsive portfolio interface
- Research and project showcase
- Technical skills and certifications
- Project documentation and reports
- Animated interactions

## Run Locally

Requirements: Node.js 20 or newer and npm.

Clone the repository:

`git clone https://github.com/SyedSaif101/portfolio.git`

Navigate into the project:

`cd portfolio`

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

## Production Build

Run `npm run build` to generate the production build.

## Deployment

The website is deployed through GitHub Pages using GitHub Actions.
